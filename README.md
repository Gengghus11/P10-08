# P10-08
This is a project Stock Trading Trend Analysis


Before anything, create a virtual environment and download the following libraries
1. flask
2. yfinance
3. pandas
4. matplotlib (can be redundant)

tldr: pip install flask yfinance panda matplotlib
once installed, run the __init__.py file and view the working prototype at http://127.0.0.1:5000/


the backend logic of this project is being coded in python
this project utilise the flask framework which passes the arguments from the python backend to the front-end html page using jinja.
